# estudio-arquitectura

Landing site `site-estudio-arquitectura`, an npm workspace of landing-factory. See [sites/README.md](../README.md) for the conventions.

```bash
npm run dev -w site-estudio-arquitectura      # dev server
npm run build -w site-estudio-arquitectura    # static build into sites/estudio-arquitectura/dist/
npm run check -w site-estudio-arquitectura    # astro check
npm run qa -- --site estudio-arquitectura     # full QA for this site only
```
