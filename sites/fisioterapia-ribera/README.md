# fisioterapia-ribera

Landing site `site-fisioterapia-ribera`, an npm workspace of landing-factory. See [sites/README.md](../README.md) for the conventions.

```bash
npm run dev -w site-fisioterapia-ribera      # dev server
npm run build -w site-fisioterapia-ribera    # static build into sites/fisioterapia-ribera/dist/
npm run check -w site-fisioterapia-ribera    # astro check
npm run qa -- --site fisioterapia-ribera     # full QA for this site only
```

Deploy target (Cloudflare Pages project by default) and its settings: [site.config.json](site.config.json); guides in docs/deploy/. Asset licenses: [CREDITS.md](CREDITS.md).
