# samurai

Landing site `site-samurai`, an npm workspace of landing-factory. See [sites/README.md](../README.md) for the conventions.

```bash
npm run dev -w site-samurai      # dev server
npm run build -w site-samurai    # static build into sites/samurai/dist/
npm run check -w site-samurai    # astro check
npm run qa -- --site samurai     # full QA for this site only
```
