# app-finanzas

Landing site `site-app-finanzas`, an npm workspace of landing-factory. See [sites/README.md](../README.md) for the conventions.

```bash
npm run dev -w site-app-finanzas      # dev server
npm run build -w site-app-finanzas    # static build into sites/app-finanzas/dist/
npm run check -w site-app-finanzas    # astro check
npm run qa -- --site app-finanzas     # full QA for this site only
```
