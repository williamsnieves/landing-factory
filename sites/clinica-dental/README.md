# clinica-dental

Landing site `site-clinica-dental`, an npm workspace of landing-factory. See [sites/README.md](../README.md) for the conventions.

```bash
npm run dev -w site-clinica-dental      # dev server
npm run build -w site-clinica-dental    # static build into sites/clinica-dental/dist/
npm run check -w site-clinica-dental    # astro check
npm run qa -- --site clinica-dental     # full QA for this site only
```
