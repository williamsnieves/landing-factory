# panaderia

Landing site `site-panaderia`, an npm workspace of landing-factory. See [sites/README.md](../README.md) for the conventions.

```bash
npm run dev -w site-panaderia      # dev server
npm run build -w site-panaderia    # static build into sites/panaderia/dist/
npm run check -w site-panaderia    # astro check
npm run qa -- --site panaderia     # full QA for this site only
```

Pages project and production branch: [site.config.json](site.config.json). Asset licenses: [CREDITS.md](CREDITS.md).
