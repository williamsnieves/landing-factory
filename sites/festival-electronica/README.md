# festival-electronica

Landing site `site-festival-electronica`, an npm workspace of landing-factory. See [sites/README.md](../README.md) for the conventions.

```bash
npm run dev -w site-festival-electronica      # dev server
npm run build -w site-festival-electronica    # static build into sites/festival-electronica/dist/
npm run check -w site-festival-electronica    # astro check
npm run qa -- --site festival-electronica     # full QA for this site only
```

Pages project and production branch: [site.config.json](site.config.json). Asset licenses: [CREDITS.md](CREDITS.md).
